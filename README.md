# Route Analyzer - Многопоточный анализ маршрутов с онлайн-мониторингом

Анализирует частоту команд поворота ('R') в маршрутах робота-доставщика, отображая текущего лидера частоты в реальном времени.

## Как работает:

1.  Генерирует 1000 маршрутов (строк из 'R', 'L', 'F').
2.  Подсчитывает количество 'R' в каждом маршруте.
3.  Ведет статистику частоты для каждого количества 'R'.
4.  **Параллельно** отображает лидера по частоте в режиме реального времени.

## Запуск:

1.  Склонируйте репозиторий (ветка `freqlog`).
2.  Откройте проект в IntelliJ IDEA.
3.  Запустите класс `Main`.

## Ключевые технологии:

*   Многопоточность (ExecutorService)
*   Синхронизация потоков (wait, notify, synchronized)

## Дополнительно:

*   Отдельный поток для вывода текущего лидера.
*   Использование `wait()`/`notify()` для сигнализации потокам.
*   Потокобезопасный доступ к общей статистике.
